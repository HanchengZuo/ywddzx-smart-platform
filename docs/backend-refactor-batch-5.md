# Flask 渐进式重构：本地打包与归档发布

日期：2026-10-16。保留前四批全部未提交改动；本轮直接完成实现、验证和收尾，不再设置额外审阅停顿。不更新版本、不提交或推送 Git、不部署、不重启现有服务。

## 范围与结构

已核对工作区、README、第四批说明、相关调用位置、既有测试和运行环境，未发现适用的 AGENTS.md。本批只提取本地备份文件操作，不触及数据库命令、恢复、权限、任务锁或调度。

新增 `backend/backups/local_files.py`，包含六项职责：

- 本地备份列表过滤、元数据读取、排序及最多返回 20 项。
- storage 备份路径排除判断和排除目录的构造。
- storage 文件遍历与 ZIP 入包，保留原目录剪枝和名称转换。
- 复制到目标目录内唯一暂存文件，再通过 os.replace 发布固定名称的成品。
- 按原名称规则清理旧本地备份，保留指定成品。

```text
原管理接口 / create_full_backup_archive
  -> app.py 同名函数（原签名、调用点保留）
  -> backups/local_files.py
       显式传入规范化目录、备份前缀、时区、storage/config 路径
       以及原排除目录和路径判断回调
  -> 本地文件 / 原 ZIP 对象

原创建编排：数据库导出 -> ZIP 关闭 -> 本地发布 -> 清理旧包
            -> 临时目录关闭 -> COS 上传 -> 返回结果
```

新模块不导入 app、Flask、数据库或 COS SDK，不传应用整体命名空间，不创建线程、锁或全局服务。模块导入不执行 I/O。路径、时区等应用配置仍由 app.py 在每次调用时提供；原配置规范化、SDK 适配、校验和传输模块均未改动。

相对本轮开始，app.py 净减少 70 行，仅六个既有文件辅助函数体和一条导入变化。其余函数（含 create_full_backup_archive、全部接口、恢复和调度）、类与初始化语句 AST 不变；前四批模块逐字节不变。

## 保持的契约

| 边界 | 保留行为 |
| --- | --- |
| 接口与权限 | URL、方法、endpoint、认证/管理权限、操作人、下载及响应字段、错误状态不变；没有新增文件访问入口，片区/站点/检查表权限不变 |
| 路径 | 原目标目录规范化仍在 app.py；排除目录的顺序、去重、位于 storage 外或等于 storage 本身时的处理不变；路径仍按 abspath/commonpath 判断 |
| 打包 | 原 os.walk 顺序和默认不跟随目录链接行为不变，仍原地修改 dirs 剪枝；排除报告导出目录、相关备份目录、配置文件和 storage 根下匹配名称的 ZIP；嵌套普通目录中的同名 ZIP 仍可入包 |
| 成员与文件 | 原文件内容、ZIP 名称前缀及反斜杠转换规则保持；普通文件链接仍沿用原读取目标行为；不新增快照、重试、扫描或压缩策略 |
| 列表 | 仍只列匹配前缀和 .zip 的文件；按原时区格式化修改时间、稳定倒序并截取 20 项；目录不存在返回空数组，其他 I/O 异常照常传播 |
| 发布 | 创建目标目录 -> 唯一隐藏暂存路径 -> copy2 -> 同目录 os.replace -> finally 清理暂存文件；复制/替换失败前不删除旧成品，不删除源文件 |
| 清理 | 原 listdir 顺序逐条删除匹配文件，保留规范化 keep_path，不删除同名目录/其他文件；删除中途失败不重试或回滚；普通备份文件链接仅被 unlink，不删除链接目标 |
| 异常 | 发布 finally 的清理异常仍可能覆盖先前复制异常；发布后旧包清理失败不会撤销新成品；不通过结构迁移新增补偿或改变错误优先级 |
| 编排与事务 | 保留导出、发布、清理及 COS 调用先后关系；授权连接关闭、锁获取/释放、配置保存和事务边界不变，数据库与恢复实现没有改动 |

## 保留风险与未纳入边界

- 多 worker 的进程内锁/调度标记不共享，文件发布没有新增互斥。两个发布者都可能成功，最后写入者覆盖成品；同目录替换不等于调度唯一性或断电耐久性，本批没有新增 fsync。
- 备份不是数据库和 storage 的共同快照，打包时文件变化或消失仍可导致失败；普通文件链接会沿用原行为读取目标，未新增链接白名单或 realpath 排除策略。
- 清理逐条进行，不具备事务性；发布后清理失败可能留下新成品和部分旧包；暂存清理失败可能留下隐藏文件或覆盖原异常。
- 原 JSON 非原子写入、配置与任务竞争、下载前释放锁、COS 部分删除、归档预检限制及数据库/storage 恢复非整体原子等风险保持原样。

本轮约定的本地文件边界已完成实现和验证，不要求再进行中途审阅。数据库命令/恢复和自动调度不属于本轮范围；后续若继续处理，应先补齐其命令参数、失败与后台并发测试，功能性修复仍须与结构调整分开。
